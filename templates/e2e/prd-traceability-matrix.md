# PRD → E2E 场景追溯矩阵

> **用途**: 确保 E2E 测试完整覆盖 PRD 的所有业务规则，杜绝设计-执行脱节。
> **生成时机**: Stage 2 测试设计阶段，由 mvp-scenario-test Agent 基于 PRD 生成。
> **验收时机**: Stage 4 集成验收阶段，由 mvp-verifier Agent 逐行核对。
>
> **设计方法论**（来源: retrospective-stage1-4.md §D-08）:
>   1. PRD 逐章节提取可测断言
>   2. 按业务能力分组（非功能模块）
>   3. 生成覆盖矩阵（每章至少 1 场景，每组至少 1 P0）
>   4. 对照设计文档反向校验
