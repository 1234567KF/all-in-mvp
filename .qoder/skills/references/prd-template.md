## Chapter 9: 验收标准 🟡

### 9.1 集成测试场景
**Happy Path**（≥ 业务线数）：
```gherkin
Scenario: INT-HP-001 - [名称] (P0)
  Given [前置条件]
  When [操作]
  Then [预期结果] (Frontend/Backend)
```

**Exception Path**（≥ 5 条）：
```gherkin
Scenario: INT-EP-001 - [名称] (P0)
  Given [前置条件]
  And [异常条件]
  When [触发异常]
  Then [错误处理] (Frontend/Backend)
```
