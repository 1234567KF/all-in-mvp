# 异常处理与边界值完整性规则

> 本文档为 `kf-mvp-prd-generator` Phase 1 Step 9 的异常处理规则。
> 每张页面 MUST 输出异常处理与边界值表。

---

## 一、必须覆盖的 5 类异常场景

| 异常类型 | 说明 | 示例 |
|---------|------|------|
| **权限不足** | 用户角色无权执行操作 | 普通用户访问管理页面 → 403 |
| **数据冲突** | 并发操作导致数据不一致 | 两人同时编辑同一订单 → 乐观锁冲突 |
| **外部依赖失败** | 第三方服务不可用 | 支付网关超时 → 订单状态不变 |
| **格式非法** | 输入数据不符合规则 | 手机号格式错误 → 前端拦截 + 后端校验 |
| **并发操作** | 重复提交、快速点击 | 重复点击"提交"按钮 → 幂等性保护 |

---

## 二、必须覆盖的 5 类边界值

| 边界类型 | 定义 | 示例 |
|---------|------|------|
| **最大输入长度** | 字符串字段的长度上限 | 用户名字段：≤ 50 字符；超长截断或拒绝 |
| **数值范围** | 数字字段的上下界 | 价格：0 ~ 999999.99；负数→拒绝，超大→拒绝 |
| **特殊字符** | 导致注入或解析错误的字符 | XSS 脚本标签、SQL 注入字符、emoji、零宽字符 |
| **空值/null** | 可选字段为空时的行为 | 备注为空→允许保存；手机号为空→允许但发送提醒 |
| **枚举越界** | 枚举字段收到未定义值 | 状态字段收到 `"unknown"` → 拒绝 |

## 四、按页面类型的异常覆盖要求

### 列表型页面
| # | 必覆盖项 |
|---|---------|
| 1 | 空数据状态（列表无数据时的展示） |
| 2 | 分页边界（第 0 页、超大页码） |
| 3 | 搜索无结果 |
| 4 | 权限过滤（用户只能看到自己有权限的数据） |
| 5 | 并发刷新（数据在浏览期间被其他人删除） |

### 表单型页面
| # | 必覆盖项 |
|---|---------|
| 1 | 必填字段全部为空时提交 |
| 2 | 单个字段边界值（最大长度字符串、最大/最小数值） |
| 3 | XSS 注入（`<script>alert(1)</script>` 等） |
| 4 | 重复提交（快速双击提交按钮） |
| 5 | 外部依赖超时（如上传文件到 OSS 超时） |

### 统计型页面
| # | 必覆盖项 |
|---|---------|
| 1 | 无数据时图表展示 |
| 2 | 极端数值（全 0、超大值） |
| 3 | 日期范围越界（结束日期 < 开始日期） |
| 4 | 数据量大时的加载性能 |
| 5 | 筛选条件组合后无结果 |

## 五、后端接口异常覆盖

所有接口 MUST 覆盖：

| 场景 | 预期 HTTP 状态码 | 预期错误码 |
|------|-----------------|-----------|
| 参数缺失 | 400 | `ERR_BAD_REQUEST` |
| 参数格式错误 | 400 | `ERR_VALIDATION` |
| 资源不存在 | 404 | `ERR_NOT_FOUND` |
| 未认证 | 401 | `ERR_UNAUTHORIZED` |
| 无权限 | 403 | `ERR_FORBIDDEN` |
| 数据冲突 | 409 | `ERR_CONFLICT` |
| 服务器内部错误 | 500 | `ERR_INTERNAL` |
