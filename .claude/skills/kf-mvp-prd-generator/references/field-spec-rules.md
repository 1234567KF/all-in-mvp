# 字段规格完整性规则

> **用途**：Phase 1 Step 6 和 Step 6.5 生成字段规格时加载。本文档定义字段规格表的输入类型枚举、校验规则格式、联动规则格式等规范。

---

## 输入类型枚举

| 输入类型 | 代码值 | 适用场景 | 说明 |
|---------|--------|---------|------|
| 用户输入 | text | 单行文本、多行文本 | 自由的键盘输入 |
| 下拉单选 | select | 从有限选项中选择一个 | 选项≤20个时推荐 |
| 下拉多选 | multi-select | 从有限选项中选择多个 | 选项≥3个且可多选时推荐 |
| 单选组 | radio | 2-5个互斥选项 | 选项少（2-5个）时比下拉更直观 |
| 多选组 | checkbox | 从一组选项中选择多个 | 选项少（2-5个）时推荐 |
| 日期选择器 | date | 选择日期 | 含日期范围选择器 |
| 日期时间 | datetime | 选择日期+时间 | 含精确到时分秒 |
| 时间选择器 | time | 选择时间 | 时分秒 |
| 文件上传 | file | 上传图片/文档 | 可指定文件类型和大小限制 |
| 开关 | switch | 二选一状态（是/否、启用/禁用） | 布尔类型 |
| 级联选择 | cascader | 有层级关系的数据 | 如省市区三级联动 |
| 穿梭框 | transfer | 从候选列表中选择若干项 | 选择后显示在右侧 |
| 富文本 | richtext | 格式化的文本编辑 | 含字体/颜色/图片嵌入 |
| 滑块 | slider | 在连续或离散范围内选择值 | 如价格范围选择 |

## 数据来源枚举

| 数据来源 | 说明 | 使用场景 |
|---------|------|---------|
| 静态 | 前端写死的固定数据 | 性别、状态枚举等固定选项 |
| API | 从后端接口动态获取 | 用户列表、部门树等动态数据 |
| 计算 | 由其他字段值自动计算得出 | 总价=单价×数量 |
| 配置 | 从系统配置表中读取 | 系统参数、自定义字典项 |
| 关联 | 从关联实体自动带入 | 选择订单后自动带出客户信息 |

## 校验规则格式

校验规则使用 `校验类型:规则表达式` 格式组织。

### 校验类型枚举

| 校验类型 | 格式示例 | 说明 |
|---------|---------|------|
| required | required | 必填校验，无表达式 |
| max_length | max_length:50 | 最大字符长度 |
| min_length | min_length:2 | 最小字符长度 |
| range | range:0-999999.99 | 数值范围（最小值-最大值） |
| regex | regex:^1[3-9]\d{9}$ | 正则表达式匹配 |
| enum | enum:A,B,C | 枚举值校验 |
| unique | unique | 唯一性校验 |
| email | email | 邮箱格式校验 |
| phone | phone | 手机号格式校验 |
| url | url | URL格式校验 |
| id_card | id_card | 身份证号格式校验 |
| date_range | date_range:2024-01-01~2025-12-31 | 日期范围 |
| cross_field | cross_field:end_date > start_date | 跨字段校验（如结束日期>开始日期） |
| custom | custom:业务规则名 | 自定义业务规则校验 |

### 完整校验例子

| 校验对象 | 校验类型 | 校验规则 | 错误提示 | 校验位置 |
|---------|---------|---------|---------|---------|
| 手机号 | regex | ^1[3-9]\d{9}$ | 请输入11位有效手机号 | 双端 |
| 用户名称 | required + max_length | required;max_length:50 | 请输入用户名称（最长50字符） | 前端 |
| 订单金额 | range | 0.01-999999.99 | 订单金额范围0.01~999999.99元 | 双端 |
| 邮箱 | email | email | 请输入有效邮箱地址 | 前端 |
| 工单编号 | unique | unique | 工单编号已存在 | 后端 |

## 字段联动规则格式

### 联动行为枚举

| 行为 | 说明 | 示例 |
|------|------|------|
| show | 显示字段 | is_company=是 → company_name:show |
| hide | 隐藏字段 | is_company=否 → company_name:hide |
| enable | 启用字段 | status=审核中 → reject_reason:enable |
| disable | 禁用字段 | status=已完成 → edit_btn:disable |
| required | 设为必填 | payment_type=分期 → installment_count:required |
| optional | 设为可选 | payment_type=一次性 → installment_count:optional |
| set_value | 自动填充值 | city=北京 → district:set_value(海淀区) |
| filter_options | 过滤选项 | province=广东 → city:filter_options(广州,深圳,珠海...) |
| clear | 清空已填值 | type=个人 → company_name:clear |
| call_api | 触发API调用 | select_order → customer_info:call_api(/api/orders/{id}) |

### 完整联动例子

条件显示：is_company=是 → company_name:show、is_company=是 → tax_id:show + required
级联过滤：province=北京 → city:filter_options(东城区,西城区,朝阳区...)
状态驱动：status=审核通过 → edit_btn:disable、status=审核中 → reject_reason:enable + required
关联数据：select_customer=customer_id → customer_info:call_api(/api/customers/{id})

## 新增/编辑/查看三态差异规则

| 操作态 | 字段行为 | 说明 |
|--------|---------|------|
| 新增 | 可编辑 / 隐藏 | 创建模式。可填字段默认编辑；系统字段（ID、创建时间）隐藏 |
| 编辑 | 可编辑 / 只读 / 隐藏 | 修改模式。关键标识（订单号）设为只读；不可改字段隐藏 |
| 查看 | 显示 / 隐藏 | 详情模式。有值字段默认显示；内部字段（排序号）可隐藏 |

### 三态差异表模板

| 字段名 | 新增态 | 编辑态 | 查看态 | 差异化原因 |
|--------|-------|-------|-------|-----------|
| 订单编号 | 隐藏（自动生成） | 只读 | 显示 | 唯一标识不可改 |
| 客户名称 | 可编辑 | 可编辑 | 显示 | 可随时修改 |
| 订单金额 | 可编辑 | 只读 | 显示 | 金额确认后不可更改 |
| 审核意见 | 隐藏 | 隐藏 | 显示 | 仅在审核流程中使用 |
| 状态 | 隐藏（默认"待审核"） | 只读 | 显示 | 通过工作流变更，不可手动编辑 |

## 操作按钮显示条件规则

| 按钮名 | 显示条件 | 权限要求 | 适用状态 | 说明 |
|--------|---------|---------|---------|------|
| 提交审核 | 仅草稿状态可见 | 录入角色 | 草稿 | 提交后进入审核流程 |
| 审核通过 | 仅待审核状态可见 | 审核角色 | 待审核 | 审核通过后进入已通过 |
| 驳回 | 仅待审核状态可见 | 审核角色 | 待审核 | 驳回后回到草稿状态 |
| 编辑 | 非已审核、非已完成 | 录入角色 | 草稿/驳回 | 已审核数据不可编辑 |
| 删除 | 仅草稿状态可见 | 管理员 | 草稿 | 已入流程数据不可删除 |
| 回退 | 仅已审核状态可见 | 审核角色 | 已审核 | 特殊情况下的回退操作 |
| 导出 | 始终可见 | 所有角色 | - | 权限由接口控制 |
