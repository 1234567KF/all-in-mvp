# SDD 需求采集 Excel 结构化解析规则

> 本文档为 `kf-mvp-prd-generator` Phase 0 SDD 路由的解析规则。
> 仅在用户提供 SDD 需求采集 Excel 模板时加载。

---

## 识别触发条件

检测到 `.xlsx` 文件且满足以下条件时，判定为 SDD 模板：
- ReadMe Sheet 第一行包含 `SDD需求采集模板`
- Sheet 名称遵循 `SheetN-ChineseName` 格式（如 `Sheet1-项目基础信息`）

---

## 解析规则

### Sheet1 — 项目基础信息

提取字段：
| Excel 列 | 映射到 PRD | 说明 |
|----------|-----------|------|
| 项目名称 | Chapter 1.1 业务目标 | 项目标题 |
| 项目背景 | Chapter 1.1 业务目标 | 为什么做 |
| 目标用户 | Chapter 1.2 目标用户角色 | 角色列表 |
| 业务目标 | Chapter 1.1 成功指标 | 量化指标 |

### Sheet2~Sheet13 — 业务线/模块需求

按 Sheet 逐个解析，每个 Sheet = 一个功能模块。

| Excel 字段 | 映射到 PRD |
|-----------|-----------|
| 功能名称 | Chapter 6.X 功能名 |
| 功能描述 | 维度1 — 描述 |
| 优先级 | P0/P1/P2 标记 |
| 业务规则 | 维度3 — 业务规则 |
| 验收标准 | 维度2 — 验收标准 |
| 字段定义 | 维度6 — 字段规格 |

### Sheet14 — AI 指令配置

提取字段：
| Excel 列 | 用途 |
|----------|------|
| 技术栈偏好 | 覆盖默认技术栈时的确认问题 |
| UI 组件库 | Chapter 3.2 技术约束 |
| 不做事项 | Chapter 3.3 Out of Scope |

---

## 解析后流程

1. 提取 Sheet1 和 Sheet14 数据
2. **跳过** Q2-Q8 口头提问
3. 进入 Phase 0.5 项目上下文自动检测
4. SDD 数据与检测值不一致 → 向用户确认
5. 进入 Phase 1 PRD 生成

---

## 与标准流程的差异

| 标准流程 | SDD 路由 |
|---------|---------|
| Q1-Q8 逐一提问 | 跳过 Q2-Q8 |
| 用户口头回答 | 从 Excel 解析 |
| 功能需求需推理 | 从 Sheet2-13 直接提取 |
| 技术栈需确认 | 从 Sheet14 提取，冲突时确认 |
