# 字段规格完整性规则

> 本文档为 `kf-mvp-prd-generator` Phase 1 Step 6/6.5 的字段规格规则。
> 所有页面 MUST 按类型输出对应的字段规格表。

---

## 一、输入类型枚举

| 输入类型 | 说明 | 适用场景 |
|---------|------|---------|
| text | 单行文本 | 姓名、标题、简短描述 |
| textarea | 多行文本 | 详细描述、备注 |
| number | 数字输入 | 数量、价格、排序号 |
| select | 下拉选择 | 枚举值、类型选择 |
| multi-select | 多选下拉 | 标签、分类 |
| date | 日期选择 | 日期字段 |
| datetime | 日期时间选择 | 时间戳字段 |
| radio | 单选按钮 | 少量互斥选项 |
| checkbox | 复选框 | 开关、布尔值 |
| file | 文件上传 | 图片、附件 |
| cascader | 级联选择 | 省市区、组织层级 |
| autocomplete | 自动补全 | 搜索选择、关联选择 |
| readonly | 只读显示 | 系统计算、不可编辑字段 |

## 三、表单型页面/弹窗字段总表

| 字段名 | 字段类型 | 输入类型 | 数据来源 | 必填 | 校验规则 | 条件显示规则 | 联动规则 | 新增态 | 编辑态 | 查看态 | 说明 |
|--------|---------|---------|---------|------|---------|------------|---------|--------|--------|--------|------|

**三态差异说明**：
- **新增态**：字段在新创建时的可见/可编辑状态
- **编辑态**：字段在编辑已有数据时的可见/可编辑状态
- **查看态**：字段在只读查看时的显示方式

**条件显示规则格式**：`IF <字段名> = <值> THEN 显示/隐藏`

**联动规则格式**：
```
联动类型：值联动 / 选项联动 / 校验联动
触发字段：<字段名>
目标字段：<字段名>
规则：IF <触发条件> THEN <联动动作>
```

---

## 四、校验规则格式

| 校验类型 | 规则表达式 | 示例 |
|---------|-----------|------|
| 必填 | `required` | 字段不能为空 |
| 长度 | `len(min, max)` | `len(2, 50)` — 2到50个字符 |
| 范围 | `range(min, max)` | `range(0, 99999)` — 数值范围 |
| 格式 | `pattern(/regex/)` | `pattern(/^1[3-9]\d{9}$/)` — 手机号 |
| 唯一性 | `unique(table, field)` | `unique(users, email)` |
| 外键 | `exists(table, field)` | `exists(categories, id)` |
| 业务规则 | `rule(name)` | `rule(start_before_end)` |

## 最少字段规则

- 列表型页面：≥ 5 个列表字段 + ≥ 2 个查询字段 + ≥ 1 个操作按钮
- 表单型页面：≥ 3 个表单字段，含完整的 3 态差异
- 统计型页面：≥ 2 个统计字段 + ≥ 1 个筛选条件
