# MSVP — 强制冒烟验证协议

> 来源：《手动驾驶体验军团白皮书》§1.6

## 核心理念

> **测试通过 ≠ 应用能跑。** 几百个单元测试全部绿灯，不等于用户打开浏览器能看到正确的页面。必须由一个独立的验证 Agent，从零冷启动应用，用真实浏览器点击核心流程，截图作为通过证据。

## 为什么单元测试不够

| 测试层 | 验证了什么 | 验证不了什么 |
|--------|----------|------------|
| 单元测试 | 函数逻辑正确性 | 路由是否正确挂载、中间件顺序 |
| API 集成测试 | 接口 in/out 正确性 | 页面渲染、CSS 布局、菜单显示 |
| 组件测试 | 组件隔离渲染 | 组件在真实页面中的组合效果、路由跳转 |
| E2E 测试 | 脚本化的浏览器操作 | **视觉第一印象**：菜单错位、按钮重叠、文字截断 |

## 三个等级

| 等级 | 触发时机 | 内容 | 执行者 | 耗时 |
|------|---------|------|--------|------|
| MSVP-Lite | Stage3 前端页面 DONE 前 | 单页渲染+核心交互 | 独立验证 Agent | 5-10min |
| MSVP-Standard | Stage4 后端合并后 & 联调后 | 核心用户旅程端到端 | 独立验证 Agent | 15-30min |
| MSVP-Full | Stage4 全部完成，交付前 | 全功能冒烟+全菜单 | 独立验证 Agent | 30-60min |

## MSVP 标准流程

```
Step 1: 冷启动
  ├── git clean -fd（或全新 clone）
  ├── npm install（从零安装依赖）
  ├── npm run db:push（初始化数据库）
  ├── npm run db:seed（种子数据）
  └── npm run dev（启动开发服务器）

Step 2: 打开浏览器
  ├── 使用 Playwright（有头模式）
  ├── 打开 Chrome DevTools Console
  └── 视口 1920x1080

Step 3: 执行冒烟路径
  ├── 导航到首页 → 截图
  ├── 遍历所有菜单项（逐一检查 404）
  ├── 执行核心用户旅程
  └── 每个关键步骤 → 截图

Step 4: A 类 Bug 检查
  ├── Console error → P0
  ├── 404 请求 → P0
  ├── 菜单完整性 → P0
  ├── 核心流程走通 → P0
  └── 页面布局异常 → P0

Step 5: 输出验证报告
```

## A 类阻塞 Bug 清单（零容忍）

| 编号 | 判定标准 | 检测方式 |
|------|---------|---------|
| A1 | 应用无法启动 | `npm run dev` 报错退出 |
| A2 | 首页/登录页白屏 | 导航截图全白 |
| A3 | 核心菜单 404 | 逐一检查菜单项 |
| A4 | 登录流程不可用 | 输入正确凭证→登录失败 |
| A5 | 核心 CRUD 不可用 | 创建→列表→编辑→删除任一步失败 |
| A6 | Console 红色 Error | DevTools error 级别日志 |
| A7 | 页面布局错乱 | 按钮重叠/文字截断/图片丢失 |
| A8 | 环境变量/配置缺失 | 应用启动但功能异常 |

> **门禁**：A1-A8 必须全部为零。任何一个 → 不通过 → 修复 → 重新 MSVP → 清零才放行。

## MSVP 检查点

| 检查点 | 触发时机 | 等级 | 通过条件 |
|--------|---------|------|---------|
| MSVP-1 | 所有前端页面 DONE 后 | Lite | 单页无 A1/A2/A7 |
| MSVP-2 | Stage4 后端合并后 | Standard | A1-A8 全部零 |
| MSVP-3 | Stage4 前后端联调后 | Standard | 核心旅程走通 + A1-A8 零 |
| MSVP-4 | Stage4 全部完成 | Full | 全菜单+全页面，A1-A8 零 |

## 验证 Agent 独立性要求

| 要求 | 说明 |
|------|------|
| 不能是开发 Agent | 写代码的 Agent 不能验证自己的代码 |
| 只能读产物不读代码 | 看 PRD/spec/验收标准，不看实现代码 |
| 只报告事实不分析根因 | 报告现象，不分析哪个文件哪一行 |
| 截图不可省略 | 每个检查步骤必须有截图证据 |
