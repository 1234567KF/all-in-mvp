# 异常处理与边界值完整性规则

> **用途**：Phase 1 Step 9 填充 Chapter 9.3 异常处理与边界值表时加载。本文档定义异常场景描述格式、边界值定义规范、覆盖门禁标准。

---

## 异常场景分类

| 异常类别 | 说明 | 优先级 | 覆盖要求 |
|---------|------|-------|---------|
| 权限不足 | 用户无操作权限 | P0 | 每张页面至少1条 |
| 数据冲突 | 多人同时编辑同一条数据 | P0 | 每张表单页面至少1条 |
| 外部依赖失败 | 第三方服务不可用/超时 | P0 | 涉及外部调用的功能必覆盖 |
| 格式非法 | 用户输入不符合格式要求 | P0 | 每张表单页面至少1条 |
| 并发操作 | 多用户同时提交相同操作 | P1 | 每张表单页面至少1条 |
| 必填为空 | 用户未填写必填字段 | P0 | 每张表单页面至少1条 |
| 数据不存在 | 引用的数据已被删除 | P1 | 有关联引用的页面必覆盖 |
| 状态冲突 | 当前状态不允许该操作 | P0 | 有状态流转的功能必覆盖 |
| 数据超限 | 导入/查询结果超过限制 | P1 | 有导入/导出/批量查询时覆盖 |
| 网络异常 | 前端请求网络不可达 | P1 | 移动端/小程序必覆盖 |

## 边界值定义规范

### 字符串类型

| 边界值维度 | 规范 | 示例 |
|-----------|------|------|
| 最大输入长度 | 字段允许的最多字符数 | max_length:200 |
| 最小输入长度 | 字段要求的最少字符数 | min_length:2 |
| 特殊字符 | 不允许/允许的特殊字符集 | 不允许: @#$%^&*() |
| 空白字符 | 前/后空格处理方式 | 自动trim / 不允许空格 |
| Unicode字符 | 是否允许emoji/中文 | 允许中文，不允许emoji |
| 空值 | 空字符串/空值的处理 | 非必填时视为无值 |

### 数值类型

| 边界值维度 | 规范 | 示例 |
|-----------|------|------|
| 最大值 | 字段允许的最大值（含） | max:999999.99 |
| 最小值 | 字段允许的最小值（含） | min:0.01 |
| 精度 | 小数位数 | decimal:2 |
| 负值 | 是否允许负数 | 不允许负数 |
| 零值 | 零值是否有特殊含义 | 零值 = 免费 |
| 越界 | 超过最大值的处理 | 提示：金额不能超过999999.99元 |

### 日期/时间类型

| 边界值维度 | 规范 | 示例 |
|-----------|------|------|
| 最早日期 | 允许的最早日期 | 2020-01-01 |
| 最晚日期 | 允许的最晚日期 | 2099-12-31 |
| 未来/过去 | 是否允许未来日期 | 创建时间≤当前时间 |
| 时间范围 | 时间跨度限制 | 结束日期≥开始日期 |
| 空值 | 允许为空 | 空=未指定 |

### 枚举/选项类型

| 边界值维度 | 规范 | 示例 |
|-----------|------|------|
| 有效值 | 有效的枚举值列表 | PENDING, APPROVED, REJECTED |
| 无效值 | 无效的枚举值处理 | 传入无效值→返回枚举校验错误 |
| 默认值 | 未选择时的默认值 | 状态默认：PENDING |
| 空值 | 未选择时是否允许提交 | 非必填时允许空 |

## 覆盖门禁

### 每张页面的覆盖要求

| 页面类型 | 最低记录数 | 必覆盖类型 |
|---------|-----------|-----------|
| 表单型页面 | ≥ 5条 | 格式非法、必填为空、数据冲突、权限不足、状态冲突 |
| 列表型页面 | ≥ 3条 | 权限不足、数据不存在、数据超限 |
| 统计型页面 | ≥ 2条 | 权限不足、外部依赖失败 |
| 特殊页面 | ≥ 3条 | 按页面特性自定义 |

### 边界值覆盖要求

每张页面的异常记录 MUST 覆盖以下边界值类型中的至少4种：

- 最大输入长度
- 数值范围（含上界/下界）
- 特殊字符
- 空值/缺省值
- 枚举越界
- 格式非法输入

## AI 常见偷懒模式（异常处理与边界值）

| 反模式 | 表现 | 正确做法 |
|--------|------|----------|
| 边界值空缺 | 只写异常场景描述，边界值列为空 | 每条记录至少填一个边界值维度 |
| 泛化处理 | 预期处理写"系统异常"、"返回错误" | 写具体的错误提示 + 错误码 + 前端/后端标注 |
| 遗漏权限场景 | 只写数据校验类异常，不写权限/状态冲突 | 覆盖全部10种异常类别中的至少5类 |
| 边界值泛化 | 只写"边界值"不写具体数字 | 写具体的最大值/最小值/长度限制 |
| 不标注层级 | 不标注 Frontend/Backend | 每个预期处理 MUST 标注层级 |
