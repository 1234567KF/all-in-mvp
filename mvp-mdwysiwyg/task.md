## 依赖图

```
M1 (extension-host)  ─── 无依赖，可独立开发
M2 (layout-shell)    ─── 无依赖，可独立开发
M3 (content-renderer) ← M2
M4 (wysiwyg-editor)   ← M3
M5 (diff-revision)    ← M3
```

**并行策略**:
- 批次 1: M1 + M2（无依赖，完全并行）
- 批次 2: M3（依赖 M2）
- 批次 3: M4 + M5（依赖 M3，互相独立可并行）
