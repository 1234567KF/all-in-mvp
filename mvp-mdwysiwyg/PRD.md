# PRD: Markdown 所见即所得阅读器（IDE 插件）

> **版本**: v1.0  
> **状态**: 【锁定版】  
> **产品定位**: Qoder/Trae IDE 插件 — 在 IDE 内提供 Typora 级所见即所得 Markdown 阅读编辑体验，集成 Word 审阅式修订标记

---

## 1. 项目背景与目标

### 1.1 痛点

用户在 IDE 中处理 Markdown 文件时面临三个核心痛点：

| # | 痛点 | 说明 |
|---|------|------|
| P1 | **不可视** | Markdown 语法符号（`###` `**` `---` `` ``` ``）干扰阅读，Mermaid 图、表格在源码中完全不可读 |
| P2 | **改了什么不知道** | AI/人工修改后只知道"文件变了"，不知道具体哪句话变了、怎么变的 |
| P3 | **找不到位置** | 长文档想跳到某个章节，只能手动滚动或 Ctrl+F 搜标题 |

### 1.2 目标

构建一个 IDE 插件，打开 .md 文件时：
- 提供 **Typora 级所见即所得**渲染与编辑（解决 P1）
- 提供 **Word 审阅式内联修订标记**（解决 P2）
- 提供 **左侧大纲导航**快速定位（解决 P3）

### 1.3 竞品定位

| 工具 | 能渲染 | 能编辑 | 有修订标记 | 有大纲 | 集成在 IDE |
|------|:---:|:---:|:---:|:---:|:---:|
| Typora | ✅ | ✅ | ❌ | ✅ | ❌ |
| VS Code 预览 | ✅ | ❌ | ❌ | ❌ | ✅ |
| Word/WPS | ❌ | ✅ | ✅ | ✅ | ❌ |
| **本插件** | ✅ | ✅ | ✅ | ✅ | ✅ |

### 1.4 产品形态

一个 IDE 插件（兼容 Qoder/Trae/VS Code），以 WebView 面板形式展示，打开 .md 文件时激活三面板 WYSIWYG 视图。

## 2. 术语定义

| 术语 | 定义 | 全文一致性 |
|------|------|-----------|
| **WYSIWYG** | What You See Is What You Get，所见即所得 | 全文统一使用 |
| **卡片嵌套视图** | 每个标题及所属内容渲染为独立 Card，按层级嵌套堆叠的视图模式 | 与"流式视图"对立 |
| **流式视图** | Word 风格连续排版，标题→段落→表格自然流动的视图模式 | 与"卡片嵌套视图"对立 |
| **基准版本 (V0)** | 用户标记的对比基线版本，后续所有修改以此为参照 | 全文统一 |
| **修订 (Revision)** | V0 与当前版本之间的一处差异 | 与"Diff"同义 |
| **大纲** | 按 H1~H6 层级组织的文档标题树形结构 | 全文统一 |
| **内联 diff** | 修订标记直接叠加在正文文字上（非左右分屏对比） | 全文统一 |
| **Hn 徽章** | 大纲面板中用彩色圆形标记表示标题层级（H1~H6） | 仅用于大纲面板 |

## 3. 风险与约束

### 3.1 技术风险

| 风险 | 影响 | 缓解策略 |
|------|------|---------|
| WYSIWYG ↔ Markdown 双向同步复杂度高 | 编辑后源码不一致 | Markdown AST 作为唯一真相源 |
| Mermaid 渲染性能 | 大文档中多个图表导致卡顿 | 懒加载 + 可视区域内渲染 |
| WebView 与 Extension Host 通信延迟 | 编辑保存不及时 | 防抖 + 增量更新 |

### 3.2 产品约束

- 产品形态为 IDE 插件，不做独立 Web 应用
- 不支持实时多人协作编辑
- 不使用 Git 版本控制（用文件系统 diff）
- 不做移动端适配
- 标题栏不渲染 Hn 层级标签（层级通过卡片缩进+左边框传达）
- Markdown 语法标记不出现在 UI 中

## 4. 用户旅程

### 4.1 主流程

```
用户打开 .md 文件
    ↓
插件激活，加载三面板视图
    ├── 左侧：自动解析文档标题，生成大纲树
    ├── 中间：渲染所见即所得内容（默认卡片嵌套视图）
    └── 右侧：如有基准版本，显示修订时间线
    ↓
用户阅读文档
    ├── 点击大纲节点 → 主视图平滑滚动到目标位置
    ├── 切换视图模式 → 卡片嵌套 ↔ 流式
    └── 折叠/展开面板
    ↓
用户编辑内容
    ├── 点击标题栏 → 标题变为可编辑
    ├── 点击正文 → 光标定位，直接输入
    ├── 使用快捷键 → Ctrl+B 加粗、Ctrl+I 斜体
    └── Ctrl+S → 保存到 .md 源文件
    ↓
用户审阅修订
    ├── 查看内联 diff 标记（绿增/红删/橙改）
    ├── 逐条接受/拒绝修订
    ├── 一键全部接受/拒绝
    └── 回退到初始版本
    ↓
用户导出
    └── 一键导出为 DOCX（可选）
```

### 4.2 修订审阅流程

```
用户标记当前版本为基准 (V0)
    ↓
文件被修改（AI 改写或人工编辑）
    ↓
插件自动执行 V0 vs V1 diff
    ↓
中间视图叠加内联 diff 标记
    ├── 新增文字：绿色下划线
    ├── 删除文字：红色删除线
    └── 修改文字：橙色背景高亮
    ↓
用户逐条审阅
    ├── ✓ 接受 → 移除标记，确认更改
    └── ✗ 拒绝 → 展示旧版原文 → 确认后恢复
    ↓
右侧修订时间线同步更新
```

## 5. 核心领域模型

### 5.1 实体关系

```
Document (1) ──── (0..*) Revision
Document (1) ──── (1) OutlineTree
Document (1) ──── (1) RenderedView
OutlineTree (1) ── (1..*) OutlineNode
RenderedView (1) ─ (1..*) Card
Card (1) ──────── (0..*) DiffMarker
Revision (1) ──── (1..*) DiffChange
```

### 5.2 核心实体

| 实体 | 属性 | 说明 |
|------|------|------|
| **Document** | filePath, content, ast, lastModified | 当前打开的 .md 文件 |
| **BaseVersion** | content, markedAt, filePath | 基准版本 (V0) 快照 |
| **Revision** | id, timestamp, triggerer, changes[], stats | 一次修改产生的修订记录 |
| **DiffChange** | type(insert/delete/modify), oldText, newText, position, elementType, accepted | 单处差异 |
| **OutlineNode** | level(1-6), text, children[], isCollapsed | 大纲树节点 |
| **Card** | level, heading, body, children[], diffState | 渲染的卡片单元 |

### 5.3 修订记录状态图

```
[新建] ──用户接受──→ [已接受] ──→ (从时间线移除标记，保留历史)
  │
  ├──用户拒绝──→ [已拒绝] ──→ (恢复 V0 原文，从时间线移除)
  │
  └──一键全部接受──→ [全部已接受] ──→ (时间线清空)
  
[新建] ──一键全部拒绝──→ [全部已拒绝] ──→ (回退到 V0，时间线清空)
```

## 6. 功能需求

### F1: 三面板布局

**描述**: 插件界面由左侧大纲面板、中间内容面板、右侧修订面板组成。

**验收标准**:
- AC1.1: 三面板同时可见，左侧默认 240px，右侧默认 280px，中间 flex:1
- AC1.2: 左侧面板可通过顶部按钮折叠至 32px，折叠后显示竖排"大纲导航"文字和展开按钮
- AC1.3: 右侧面板可通过顶部按钮折叠至 32px，折叠后显示竖排"修订历史"文字和展开按钮
- AC1.4: 左侧面板右边缘可拖拽调整宽度（32px~400px）
- AC1.5: 右侧面板左边缘可拖拽调整宽度（32px~400px）
- AC1.6: 面板间以 1px `--border` 色竖线分隔
- AC1.7: 折叠/展开动画 200ms ease-in-out

### F2: 大纲导航面板

**描述**: 左侧面板按 H1~H6 层级展示文档标题的可折叠树形结构。

**验收标准**:
- AC2.1: 按文档标题层级生成树形结构，H1 为根级
- AC2.2: 每个节点前方显示彩色 Hn 圆形徽章（H1 深蓝、H2 蓝、H3 绿、H4 橙、H5 玫红、H6 棕灰）
- AC2.3: 有子节点的条目显示折叠箭头 `▸`/`▾`，无子节点则不显示
- AC2.4: 点击节点 → 中间主视图平滑滚动到该标题位置，目标卡片高亮闪烁 2 秒
- AC2.5: 当前滚动位置对应的节点自动高亮（蓝色背景 + 左侧 2px 竖线指示器）
- AC2.6: 顶部搜索框输入关键词，仅显示匹配分支
- AC2.7: 拖拽节点可移动该标题及所有子内容到目标位置，MD 源文件同步更新
- AC2.8: 右键节点弹出菜单：升级/降级标题、在上方插入标题、删除本章节

### F3: 卡片嵌套视图（默认）

**描述**: 每个标题及所属内容渲染为独立 Card，按层级通过 margin-left 缩进嵌套堆叠。

**验收标准**:
- AC3.1: H1 卡片 `ml-0 p-6 shadow-sm border`，标题 48px/800w
- AC3.2: H2 卡片 `ml-4 p-4 border + 左边框 primary 3px`，标题 36px/700w
- AC3.3: H3 卡片 `ml-8 p-3 border-b + 左边框 muted-foreground 2px`，标题 24px/600w
- AC3.4: H4 卡片 `ml-12 p-2 border-0 + 左边框 border 1px`，标题 20px/600w
- AC3.5: H5/H6 无边框无背景，纯缩进 `ml-14/ml-16`，标题 16px/14px 500w
- AC3.6: 同级卡片间距 gap-4，嵌套间距 gap-2
- AC3.7: 标题栏**不显示** `#`/`##` 前缀或 Hn 层级标签
- AC3.8: 层级通过卡片缩进+左边框色深传达

### F4: 流式视图

**描述**: Word 风格连续排版视图，通过工具栏一键切换。

**验收标准**:
- AC4.1: 所有卡片去除边框、背景、阴影，变为连续排版
- AC4.2: 标题字号递减（H1 2em → H6 0.9em）
- AC4.3: H1/H2 底部显示分隔线
- AC4.4: 段落间距 my-2，代码块/表格 my-4
- AC4.5: Diff 标记保留文字级样式（绿增红删橙改），但不渲染卡片级边框
- AC4.6: 工具栏按钮可一键切换，状态栏显示当前模式

### F5: 非标题元素渲染

**描述**: 正文中的各种 Markdown 元素正确渲染为富文本。

**验收标准**:
- AC5.1: `**加粗**` → 粗体文字，`*斜体*` → 斜体文字，无标记符
- AC5.2: `` `行内代码` `` → 浅灰底 + 等宽字体（JetBrains Mono）
- AC5.3: 围栏代码块 → 深色背景 + 语法高亮 + 右上角复制按钮 + 左上角语言标签
- AC5.4: 表格 → 带边框，表头加粗加底色，行 hover 高亮
- AC5.5: 引用块 → 左侧竖线 + 半透明背景 + 斜体
- AC5.6: 有序/无序列表 → 正常缩进渲染
- AC5.7: 图片 → 自适应宽度，点击灯箱放大
- AC5.8: 分隔线 → 视觉分隔线
- AC5.9: ` ```mermaid ` → 即时渲染为 SVG 图表，支持点击放大、全屏查看

### F6: WYSIWYG 编辑

**描述**: 像 Typora 一样在渲染视图上直接编辑，编辑结果写回 .md 源文件。

**验收标准**:
- AC6.1: 点击正文任意位置 → 光标定位，可直接输入/删除文字
- AC6.2: 点击卡片标题栏 → 标题变为可编辑，修改后自动更新大纲树
- AC6.3: Enter → 新建同层级段落
- AC6.4: Tab / Shift+Tab → 缩进/反缩进
- AC6.5: Ctrl+B / Ctrl+I → 加粗/斜体
- AC6.6: 粘贴图片 → 自动保存为相对路径文件，插入图片标记
- AC6.7: Ctrl+S → 保存变更到 .md 源文件
- AC6.8: Ctrl+Z / Ctrl+Y → 撤销/重做
- AC6.9: 编辑模式下修订追踪开启时，编辑操作自动标记为修订

### F7: 内联 Diff 标记

**描述**: 当加载基准版本后，中间视图原位叠加 Word "所有标记"模式的 diff 标记。

**验收标准**:
- AC7.1: 新增文字 → 绿色下划线 + 绿色文字 + 左侧绿色竖线
- AC7.2: 删除文字 → 红色删除线 + 红色文字 + 左侧红色竖线
- AC7.3: 修改文字 → 橙色背景高亮 + 左侧橙色竖线
- AC7.4: 整段/卡片新增 → 左边框绿色 + 半透明绿色背景
- AC7.5: 整段/卡片删除 → 左边框红色 + 半透明红色背景 + 所有文字加删除线
- AC7.6: 标题文字变更 → 卡片标题栏内文字变色
- AC7.7: 标题层级变更 → 旧层级卡片标记删除，新层级卡片标记插入
- AC7.8: 每处修订旁显示 ✓ 接受和 ✗ 拒绝按钮

### F8: 修订操作

**描述**: 用户可逐条或批量接受/拒绝修订。

**验收标准**:
- AC8.1: ✓ 接受 → 移除标记，确认更改
- AC8.2: ✗ 拒绝 → 展开对比卡片显示旧版/新版 → 确认后恢复原始内容
- AC8.3: 确认撤回后，对应时间线条目移除
- AC8.4: 工具栏 [✅ 全接受] → 接受所有修订，清除全部标记
- AC8.5: 工具栏 [❌ 全拒绝] → 回退到基准版本
- AC8.6: [👁️ 显示修订] 为 Toggle 按钮：显示修订 / 隐藏修订（完全干净）

### F9: 修订时间线面板

**描述**: 右侧面板按时间倒序展示所有修订记录。

**验收标准**:
- AC9.1: 每条记录显示时间戳、触发者标签（AI/人工）、变更统计（+N -M）
- AC9.2: 点击条目 → 中间主视图滚动到对应位置，修订标记闪烁 2 秒
- AC9.3: 概览 Tab 显示整体统计：新增/删除/修改数量 + 章节热力图
- AC9.4: 底部按钮：回退到初始版本、导出带修订 DOCX

### F10: 基准版本管理

**描述**: 用户可设定/更换/清除基准版本。

**验收标准**:
- AC10.1: [设为基准] → 将当前内容标记为 V0
- AC10.2: [更换基准文件] → 选择另一个 .md 文件作为 V0
- AC10.3: [清除基准] → 移除基准标记，不再显示修订
- AC10.4: 同目录下同名带版本后缀的文件自动关联

### F11: 内容插入

**描述**: 工具栏 [+ 新增] 按钮，在光标位置或文末新增内容。

**验收标准**:
- AC11.1: 点击 [+ 新增] → 弹出下拉菜单，显示 H1~H6 + 正文段落
- AC11.2: 每项左侧使用与大纲面板同色的 Hn 圆形徽章
- AC11.3: H1~H6 → 插入对应层级标题卡片 + 占位正文
- AC11.4: 正文 → 仅插入空白段落
- AC11.5: 有光标定位 → 在光标所在卡片后插入；无光标 → 文末追加
- AC11.6: 插入后自动进入编辑模式，光标定位到新内容

### F12: 工具栏

**描述**: 顶部固定工具栏，分组排列所有操作按钮。

**验收标准**:
- AC12.1: 工具栏高度 48px，底部分隔线
- AC12.2: 按钮分组：文件 | 视图 | 修订 | 导出，组间以竖线分隔
- AC12.3: 按钮采用 Ghost 风格，hover 高亮
- AC12.4: 视图模式按钮（流式/卡片）互斥激活
- AC12.5: 修订 Toggle 按钮显示激活状态

### F13: 快捷键

**描述**: 支持常用编辑和视图快捷键。

**验收标准**:
- AC13.1: Ctrl+S 保存
- AC13.2: Ctrl+Z/Y 撤销/重做
- AC13.3: Ctrl+B/I 加粗/斜体
- AC13.4: Ctrl+F 搜索 / Ctrl+H 替换
- AC13.5: Ctrl+Shift+E 切换修订追踪
- AC13.6: Ctrl+Shift+V 切换视图模式

### F14: Mermaid 图表渲染

**描述**: Mermaid 代码块即时渲染为 SVG 矢量图。

**验收标准**:
- AC14.1: ` ```mermaid ` 代码块自动渲染为 SVG
- AC14.2: 支持 graph、sequenceDiagram、classDiagram、stateDiagram
- AC14.3: 支持 subgraph 嵌套分组
- AC14.4: 点击放大查看，全屏查看按钮
- AC14.5: 渲染失败时显示源码 + 错误提示
- AC14.6: 源码可编辑，编辑后刷新图表

### F15: 状态栏

**描述**: 底部状态栏显示文档和视图状态信息。

**验收标准**:
- AC15.1: 高度 32px，背景 --muted
- AC15.2: 显示：字数、行数、视图模式、追踪状态
- AC15.3: 右侧显示快捷键提示

### F16: Diff 引擎

**描述**: 基于标题对齐的 Markdown Token 级 diff 算法。

**验收标准**:
- AC16.1: 以 Heading token 为锚点拆分章节块
- AC16.2: 块内按文本相似度（Levenshtein Ratio > 0.6）匹配段落
- AC16.3: 表格按行列对齐，单元格级 diff
- AC16.4: 代码块整体比较
- AC16.5: 未匹配段落标记为整体删除或插入
- AC16.6: 修订记录持久化到 `.{文件名}.revisions.json`

### F17: 修订持久化

**描述**: 修订记录存储在本地文件中，关闭再打开自动恢复。

**验收标准**:
- AC17.1: 修订记录存储为 `.{文件名}.revisions.json`
- AC17.2: 关闭文件后再打开，修订标记自动恢复

### F18: 导出 DOCX（可选）

## 9. 设计系统约束

- 设计系统：shadcn/ui（Radix UI + Tailwind CSS + CSS Variables）
- 字体：Inter（正文/UI） + JetBrains Mono（代码/等宽）
- 颜色：全部使用 CSS 变量（`--background`, `--foreground`, `--primary` 等）
- 圆角：全部使用 `--radius` 变量
- 动画：不超过 300ms
- 暗色主题：通过 `.dark` 类切换 CSS 变量集

## 10. 验收总标准

1. 打开任意 .md 文件，三面板正确渲染
2. 大纲树与文档标题一致，点击跳转准确
3. 卡片嵌套视图层级视觉正确（缩进+边框+字号递减）
4. 流式视图连续排版无卡片框
5. WYSIWYG 编辑后 Ctrl+S 正确写回 .md 源文件
6. 设定基准后修改文件，内联 diff 标记正确渲染
7. 逐条/批量接受拒绝修订行为正确
8. Mermaid 图表正确渲染为 SVG
9. 修订记录正确持久化
10. 面板折叠/展开/拖拽调整正确
