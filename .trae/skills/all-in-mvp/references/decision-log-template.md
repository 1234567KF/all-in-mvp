# 环节决策日志模板

> 来源：《手动驾驶体验军团白皮书》§二

## 日志文件命名

```
decisions/
  ├── stage1-prd-decisions.md
  ├── stage2-arch-decisions.md
  ├── stage2-biz-decisions.md
  ├── stage2-grill-decisions.md
  ├── stage2-mock-decisions.md
  ├── stage2-test-decisions.md
  ├── stage3-backend-<module>-decisions.md
  ├── stage3-frontend-<page>-decisions.md
  ├── stage4-integration-decisions.md
  └── stage5-retro-decisions.md
```


## 日志的生命周期

```
环节开始 → 创建日志文件（填写 Agent 角色 + 时间）
  ↓
理解确认 → 填写「理解确认阶段」
  ↓
执行中 → 逐项填写「决策记录」
  ↓
产出确认 → 填写「产出物确认阶段」
  ↓
修正（如有）→ 填写「驳回与修正记录」
  ↓
环节通过 → 勾选「环节门禁」→ 日志文件标记为 FINAL
```

## 不可变性原则

> **不可删除、不可修改已确认的决策。** 如需推翻之前的决策 → 新开一个决策日志文件，引用被推翻的决策编号并说明理由。

## 上下文摘要模板（跨 Agent 传递用）

```markdown
# 上下文摘要：从 <上游环节> 到 <下游环节>

## 传递给下游的关键信息
- <1-3 条最关键的决策>
- <1-3 条最关键的约束>
- <1-3 条需要下游特别注意的风险>

## 不需要下游关心的内容
- <明确告知下游 Agent 忽略什么，防止过度推理>
```
