# 迭代1优化记录：电商系统 + TDD测试覆盖强化

## 优化角度（新）
**5层测试覆盖模型** — 解决之前人工测试发现明显错误的根本问题

## 发现的问题
- 只有 L1(单元) + L2(API集成)，缺少 L3(数据库事务) + L4(有头浏览器) + L5(无头CI)
- 数据库事务回滚未测试 → 数据不一致bug
- 前端空状态未测试 → 空数据时UI崩溃
- 有头/无头测试配置混乱 → CI通过但人工测试失败
- 测试断言太弱 → "not null" 而不是检查具体值

## 优化内容

### 1. kf-mvp-backend-tdd/SKILL.md
- **新增5层测试覆盖模型**：L1单元/L2 API集成/L3数据库/L4有头浏览器/L5无头CI
- **新增L3数据库事务测试**：强制测试rollback on error
- **新增L4-L5 Playwright配置**：区分 `chromium-headed` 和 `chromium-headless`
- **新增边界条件测试**：空列表、空body、必填字段缺失
- **新增GREEN Phase验证清单**：覆盖率≥80%、故意破坏测试验证有效性、有头/无头结果对比
- **新增有头/无头差异对照表**：3种常见问题及解决方案
