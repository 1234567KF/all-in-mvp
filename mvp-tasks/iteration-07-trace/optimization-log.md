# 迭代7：溯源系统 — 复杂业务规则测试优化

## 需求描述

溯源/供应链系统有复杂的业务规则（链式验证、批次追踪、多层级关联），之前规则漏洞只在人工测试时发现（如：伪造溯源码通过验证、批次关联断裂）。

## 系统类型
溯源系统 (Traceability System)

## 核心问题

1. **链式完整性未测试**：断链、循环引用未检测
2. **时间一致性缺失**：后节点时间早于前节点未拦截
3. **数量守恒缺失**：产出总量超过原料总量未检测
4. **防伪校验薄弱**：码格式、校验位、重复扫描未覆盖
5. **规则冲突未检测**：过期产品在活跃批次中未发现
6. **跨模块一致性缺失**：库存与溯源数据不一致未检测

## 优化产出

### 1. kf-mvp-biz-expert/SKILL.md — 新增 Stage 3 复杂业务规则验证

- 新增链式完整性测试（完整链 + 断链 + 循环链 + 时间一致性）
- 新增批次关联测试（数量守恒 + 层级深度 + 多对多关联）
- 新增防伪验证测试（码格式 + 校验位 + 重复扫描 + 伪造检测）
- 新增规则冲突检测（互斥状态 + 过期产品 + 跨模块不一致）
- 新增业务规则验证检查清单
