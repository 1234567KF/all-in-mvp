# 迭代5：O2O系统 — 异步流程集成测试优化

## 需求描述

O2O系统有大量异步流程（下单→派单→骑手接单→配送→完成），之前异步状态同步bug只在人工测试时发现（如：订单已配送但状态未更新）。

## 系统类型
O2O系统 (Online to Offline)

## 核心问题

1. **轮询模式未测试**：前端轮询订单状态时，超时处理是否正确？
2. **WebSocket未测试**：实时推送消息是否可靠？断线重连是否正常？
3. **事件顺序未验证**：created→dispatched→delivered 顺序是否正确？
4. **幂等性未测试**：重复事件是否被正确处理？
5. **完整E2E链路缺失**：从下单到送达的完整流程未自动化测试

## 优化产出

### 1. kf-mvp-integration/SKILL.md — 新增异步流程集成测试章节

- 新增轮询模式测试（状态变更轮询 + 超时测试）
- 新增WebSocket模式测试（消息接收 + 重连 + 断线）
- 新增事件驱动测试（顺序 + 幂等 + 丢失恢复）
- 新增完整E2E流程测试（下单→派单→取货→配送→送达）
- 新增异步测试辅助函数（pollForCondition + waitForMessage）
- 新增异步流程测试覆盖率要求表
